# ACPI Predefined Names Tools

These files were provided in the original `WilliamWu-HJ.acpihelper` extension,
and appear to be used to seed the default included ACPI keywords & descriptions.

It appears that the original source of this table was the UEFI.org ACPI
specification.  The appropriate table `5.173` for version `6.4` of the ACPI
specification can be found at the following URL:

- [UEFI.org - ACPI Specification v6.4: 5.6.8. Predefined ACPI Names for Objects, Methods, and Resources - Table 5.173][1]

[1]: https://uefi.org/htmlspecs/ACPI_Spec_6_4_html/05_ACPI_Software_Programming_Model/ACPI_Software_Programming_Model.html#predefined-acpi-names
